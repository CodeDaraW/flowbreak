# ADR-0003：调度时钟、恢复与非阻断交互

- Status: Accepted
- Date: 2026-09-05
- Requirements: FB-002, FB-003, FB-004, FB-005, FB-006, FB-008, FB-009, FB-010
- Iteration: [0002](../iterations/0002-scheduler/plan.md)

## 决定

核心接收显式单调时间（秒）、空闲时长与可用状态。macOS 协调器单一 MainActor 写入，每秒采样原生输入空闲；Timer 只唤醒计算，不作为时间单位。锁屏/睡眠不计工作时长，主动休息可以跨睡眠完成。长离开恢复时清除待处理；短重启保留累计，未验证完的主动休息不跨进程认定完成。

提醒共享一个 snooze 截止时间。柔性起身只提醒一次，护眼和强提醒默认每 10 分钟重提；延迟结束可再展示。弱提示 7 秒、强提示 12 秒自动收起，自动收起/点击外部不改变累计。只等至少 2 秒输入空档，连续输入不会强制打断。主动休息启动后给予 2 秒缓冲，之后任何原生输入使尚未完成的休息中断。该过滤不分析按键内容。

眼睛到期且起身柔性将在合并窗口内到期时暂缓眼睛；起身到期后合并显示。柔性阶段“到 60 分钟再提醒”是全局静默至有效工作累计达到强阈值（不是固定墙钟倒计时），不能将起身清零。强阶段允许跳过起身；跳过起身不清除眼睛。

手动补记或跳过保留一次撤销快照，恢复被清除的累计及提醒状态，并保留期间新增工作累计；开始新休息或自然重置后失效，避免跨周期撤销。自动完成不伪装为手动修改。

保持唤醒与暂停相互独立。Agent 到期或手动恢复计时，按本次实际暂停时长决定保留/重置；停止保持唤醒本身不取消暂停。提供单独“结束 Agent”动作同时清理两者。无限保持唤醒不会阻止用户主动睡眠或合盖。退出/崩溃由进程拥有的 IOKit 断言释放，不启动脱离进程的 caffeinate。

运行快照版本化，原子写入；每 15 秒及用户动作保存。只恢复计时和提醒状态，电源断言、暂停、休息不跨重启自动恢复。事件最多保留最近 1000 条，纯本地，不记录输入内容或窗口标题。默认提醒位置为鼠标所在显示器（“当前显示器”），支持主屏与固定屏幕；不为获取前台窗口额外申请辅助功能权限。

## 后果与限制

原生空闲只能近似活动，不能区分阅读或 Agent 输入；共享检测继续延期，改用显式手动共享静默。锁屏使用会话状态/系统事件，不申请屏幕录制权限。系统通知和声音不作为提醒渠道。OS 行为需真机验证，核心单测不替代该验证。

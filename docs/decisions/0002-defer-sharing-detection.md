# ADR-0002：飞书共享自动检测暂缓

- Status: Accepted
- Date: 2026-09-05
- Requirements: FB-007
- Iteration: [0001](../iterations/0001-bootstrap/plan.md)

## 背景与证据

用户仅要求尽力支持飞书会议，明确允许没有可靠实现时先不做。见 [研究记录](../research/feishu-sharing.md)。找到 Nudge 历史实现，但依赖系统私有 DoNotDisturbServer 状态；未验证现代 macOS 或飞书兼容性。

## 决定

本轮不接入自动检测、不复制私有接口实现、不将 Focus 或飞书进程存在视为正在共享。界面明确功能未实现。后续调度先提供手动共享静默；真正加入自动检测前先做独立验证迭代。

## 替代方案与后果

私有 API、系统日志解析或辅助功能识别飞书共享工具栏都可以作为研究方向，不能视为可靠产品能力。辅助功能方案需用户授权且受版本/语言影响。状态模型需支持 active/inactive/unavailable，拒绝把能力未知当成肯定未共享。

本轮没有真实飞书会议测试，不承诺自动静默。暂缓是用户授权范围内的取舍，不是确认系统绝对无法实现。

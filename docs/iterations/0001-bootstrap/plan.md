# 0001：工程初始化

Status: blocked（仅 GUI 验收；初始化产物已交付） · 2026-09-05

## 来源与确认

用户要求先确认方案再初始化；后续批注确认 macOS 14+ arm64、中文和英文、MIT、本地 Git 无远端、SDD 迭代与决策记录。计时隔离仅为测试；护眼时起身累计继续；Agent 人工接管不取消保持唤醒；默认值可由实现方决定并允许设置；飞书自动检测允许延期。

## 范围

FB-001—FB-012 的规格与追踪；实现 FB-001/FB-011 的应用与设置骨架、FB-002/FB-003/FB-005/FB-008 的部分核心规则，以及 FB-012 文档/构建机制。关联 [ADR-0001](../../decisions/0001-native-foundation.md)、[ADR-0002](../../decisions/0002-defer-sharing-detection.md)。

非目标：完整提醒产品、真实电源/空闲/共享适配、自动浮层、日志、分发、远端和提交发布。当前 UI 必须诚实显示工程预览状态。

## 验收

- 可生成并构建 arm64 macOS 应用，能启动菜单栏并打开设置。
- 中文和英文资源齐全，设置支持语言选择与参数保存。
- 核心测试无需等待真实分钟，验证已确认语义。
- `make check` 可执行并关联规格/迭代/代码/验证。
- MIT、本地 Git main 分支，无 remote。
- 验证记录明确当前 OS 与 macOS 14 兼容性验证的区别。

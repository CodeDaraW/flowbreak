# Iteration 0007: 勿扰联动静默

Status: active

## 用户变更

2026-09-07 用户将自动识别目标从飞书会议/共享改为 macOS 勿扰。目的仍是投屏时不受休息提醒打扰；用户会自行开启勿扰，不要求 FlowBreak 操作勿扰。关联 FB-007、FB-009、FB-011。

## 已确认方案

- 官方 Focus Filter（macOS 13+，满足 14+ 范围）：用户在系统勿扰中添加 FlowBreak 过滤条件一次，后续开关由系统通知应用。实现前验证后台事件、退出后恢复及本地签名可用性。
- INFocusStatusCenter 可公开查询可接收通知的 Focus 状态，但不提供具体模式身份；不得声称它只识别勿扰，也不得将 nil/未授权解释为明确关闭。
- 零配置读取具体勿扰状态需要另行验证。旧 ADR 不允许未经新明确决策接入私有接口；当前不调用或复制此类实现。

用户已明确接受一次配置。采用官方 Focus Filter，见 ADR 0005。2026-09-07 实测发现本机临时签名缺少 Team ID，系统拒绝保存过滤条件；完成开发签名后继续验收。

## 预期行为

勿扰开启：收起自动提醒并静默自动声音，计时规则继续执行；用户主动打开 App 仍可操作。关闭：经过配置缓冲后重新计算，最多展示一个最高等级合并提醒。手动静默与系统静默必须独立保存，任一开启都保持静默；退出系统勿扰不能清除用户手动静默。未知状态不得伪装为已关闭。保留手动兜底，不再开发飞书专属自动识别。

## 验证

先区分明确模式状态与共享 Focus 状态；原生系统开关为 E2E oracle。覆盖开启/关闭、手动静默叠加、未知/不可用状态、应用重启、配置移除，以及静默时不发出自动声音。核心测试与真实系统联动分别记录。不得将编译通过称为已完成自动识别。

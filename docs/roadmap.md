# 路线图

按独立迭代实现，每轮先细化规格和验收再动工。

1. **0001 工程初始化**：双语菜单栏、设置、确定性核心、测试、SDD、MIT、本地 Git。本轮范围。
2. **调度核心**：延迟/跳过、合并、取消、撤销、输入中断、可控时钟场景模拟；对应 FB-002—FB-006。
3. **macOS 系统适配**：空闲、锁屏/睡眠、IOKit 保持唤醒、Agent 到期/人工接管、持久化恢复；FB-004、FB-008、FB-010。
4. **提醒体验**：NSPanel、非激活展示、多显示器、完整 UI、手动共享静默；FB-006、FB-007、FB-009。
5. **产品验收**：macOS 14 与当前版本真机、功耗、重启、双语、无障碍；事件记录与统计基础。
6. **可选飞书研究**：只有可靠证据后接入自动共享识别；已许可延期。
7. **公开发布**：远端由用户配置；发布身份、签名、公证、图标与安装包另行决策。

本路线图不是上述功能已经存在的声明，也不启动额外后台任务。

# FlowBreak 产品规格

状态：Accepted（2026-09-05）；实施情况单独见 [索引](requirements.json)。

## 来源与范围

来源为用户提供的休息工具聊天导出，以及本次逐条批注确认。聊天中的模型建议只在本规格明确采纳后作为默认设计。用户确认：macOS 14+、Apple Silicon、双语、MIT、本地 Git；先做工程初始化。原始聊天不公开。

| ID | 已确认需求 / 验收标准 |
|---|---|
| FB-001 | macOS 14+ arm64 菜单栏工具；无跨平台支持；可构建本地应用 |
| FB-002 | 护眼累计 20 分钟到期，休息 20 秒；只清除护眼累计，起身累计继续 |
| FB-003 | 起身 40 分钟柔性提醒、60 分钟加强提醒；完整起身休息清除两类累计 |
| FB-004 | 无操作暂停、较长自然休息重置；阈值可配置；短暂阅读不自动完成护眼 |
| FB-005 | 开始休息、补记已休息、最近一次修正可撤销；检测到操作中断休息，不清零原累计 |
| FB-006 | 相邻到期合并；延迟 3/5 分钟保证整段静默；关闭不等于跳过；跳过只重置对应周期 |
| FB-007 | 飞书共享时继续计时、自动展示全部静默；允许主动打开面板；自动检测可延期 |
| FB-008 | 保持唤醒独立于计时；Agent 启动=暂停计时+保持唤醒；人工接管只恢复计时及提醒 |
| FB-009 | 弱/强提醒均不抢焦点、不锁屏、不切 Space；多显示器位置可配置，拔屏有回退 |
| FB-010 | 本地状态恢复及事件记录；不惩罚 skip；睡眠/短重启保持状态，长离开按自然休息处理 |
| FB-011 | 简体中文、英语、跟随系统；默认参数可修改并持久保存；无需联网 |
| FB-012 | SDD 迭代与 ADR 决策历史；本地 Git 无远端；MIT；可复现构建和核心测试 |

## 默认参数

所有值允许后续调整；本轮设置界面单位为秒。

| 参数 | 默认 |
|---|---:|
| 护眼间隔 / 时长 | 1200 / 20 秒 |
| 起身柔性 / 加强阈值 | 2400 / 3600 秒 |
| 起身休息时长 | 180 秒 |
| 无操作暂停 / 自然休息重置 | 120 / 300 秒 |
| 合并窗口 / 共享结束缓冲 | 180 / 20 秒 |

有效性：均为有限正数；柔性 < 加强；暂停 < 重置；护眼时长 ≤ 起身时长；合并窗口 < 护眼间隔。非法设置不覆盖最后一次有效保存值。

## 暂不纳入

会议参与检测、日历、Focus、摄像头/麦克风、屏幕内容、视线、坐姿、手机使用检测；不区分真人与 Agent 输入，不强制休息或处罚。App Store、自动更新、签名公证与远端仓库未配置。不开启后台 AI 服务。

## 后续实现前需细化

非阻断浮层在各 Space 下的键盘/点击行为、输入缓冲和偶发移动过滤、完整撤销边界、日志保留策略、共享未知状态下的提示策略。飞书检测决策见 [ADR-0002](../decisions/0002-defer-sharing-detection.md)。这些不阻塞工程初始化，但不能按已实现处理。

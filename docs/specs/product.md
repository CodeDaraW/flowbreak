# FlowBreak 产品规格

状态：Accepted（2026-09-05）；实施情况单独见 [索引](requirements.json)。

## 来源与范围

来源为用户提供的休息工具聊天导出，以及本次逐条批注确认。聊天中的模型建议只在本规格明确采纳后作为默认设计。用户确认：macOS 14+、Apple Silicon、双语、MIT、本地 Git；已授权按关键阶段开发并及时 Git commit。原始聊天不公开。

| ID | 已确认需求 / 验收标准 |
|---|---|
| FB-001 | macOS 14+ arm64 菜单栏工具；无跨平台支持；可构建本地应用 |
| FB-002 | 护眼累计 20 分钟到期，休息 20 秒；只清除护眼累计，起身累计继续 |
| FB-003 | 起身 40 分钟柔性提醒、60 分钟加强提醒；完整起身休息清除两类累计 |
| FB-004 | 无操作暂停、较长自然休息重置；阈值可配置；短暂阅读不自动完成护眼 |
| FB-005 | 开始休息、补记已休息、最近一次修正可撤销；检测到操作中断休息，不清零原累计 |
| FB-006 | 相邻到期合并；延迟 3/5 分钟保证整段静默；关闭不等于跳过；跳过只重置对应周期 |
| FB-007 | 用户一次配置官方勿扰过滤条件后自动静默提醒与声音；保留独立手动静默；普通计时规则不变，实际系统验收待开发签名 |
| FB-008 | 保持唤醒独立于计时；Agent 启动=暂停计时+保持唤醒；人工接管只恢复计时及提醒 |
| FB-009 | 弱/强提醒均不抢焦点、不锁屏、不切 Space；多显示器位置可配置，拔屏有回退 |
| FB-010 | 本地状态恢复及事件记录；不惩罚 skip；睡眠/短重启保持状态，长离开按自然休息处理 |
| FB-011 | 简体中文、英语、跟随系统；默认参数可修改并持久保存；无需联网 |
| FB-012 | SDD 迭代与 ADR 决策历史；本地 Git 无远端；MIT；可复现构建和核心测试 |

## 默认参数

所有值允许后续调整；设置按场景显示分钟或秒，并持久保存。

| 参数 | 默认 |
|---|---:|
| 护眼间隔 / 时长 | 1200 / 20 秒 |
| 起身柔性 / 加强阈值 | 2400 / 3600 秒 |
| 起身休息时长 | 180 秒 |
| 无操作暂停 / 自然休息重置 | 120 / 300 秒 |
| 合并窗口 / 共享结束缓冲 | 180 / 20 秒 |

有效性：均为有限正数；柔性 < 加强；暂停 < 重置；护眼时长 ≤ 起身时长；合并窗口 < 护眼间隔。非法设置不覆盖最后一次有效保存值。

## 暂不纳入

会议参与检测、日历、摄像头/麦克风、屏幕内容、视线、坐姿、手机使用检测；不区分真人与 Agent 输入，不强制休息或处罚。App Store、自动更新、签名公证与远端仓库未配置。不开启后台 AI 服务。

## 当前实现约定与剩余验收

输入缓冲 2 秒、事件保留 1000 条、10 秒内撤销最近一次手动补记/跳过、非激活浮层和手动共享静默已采用 ADR-0003 的规则。非阻断浮层在各 Space 下的键盘/点击行为、锁屏与多屏仍需真机验收。飞书检测决策见 [ADR-0002](../decisions/0002-defer-sharing-detection.md)。自动共享识别不在当前开发版内，不能宣称已支持。

## Approved design baseline (2026-09-07)

r02 passed the user-authorized external design review. Native implementation follows [ADR-0004](../decisions/0004-approved-design.md) and [iteration 0006](../iterations/0006-approved-design/plan.md). Waiting for the strong movement threshold does not silence eye reminders. Explicit skip restarts its own cycle, including soft movement. Unknown app downtime preserves saved work; only observed absence proves natural rest. Weak eye reminders do not automatically repeat periodically after dismissal. Hover and expanded actions pause panel auto-dismissal.

### r02 设置与休息细节

弱/强提醒停留默认 30/15 秒，强提醒重复默认 10 分钟；3/5 分钟延迟按钮可分别隐藏。提醒声音默认关闭，休息完成声音默认开启，共享静默不播放自动声音。提醒支持显示器及四角位置，起身休息可选不切 Space 的全屏浮层。起身休息可增加 2 分钟；保持唤醒可延长或修改结束时间。点击、键盘、滚动及拖动中断休息，单纯移动指针不打断；休息面板自身的延长操作不作为中断。补记或跳过的撤销窗口为 10 秒，合并跳过作为一次修正。外观支持跟随系统、浅色、深色，仅作用于本应用。

延迟归属按护眼/起身分别持久化；任一有效延迟都抑制所有自动提醒。单项浮层延迟只登记对应项，合并浮层登记两项。开始、补记或跳过对应休息清除对应延迟；起身休息覆盖两项。旧版单一延迟快照兼容为两项延迟，避免提前打扰。撤销按钮显示具体修正类型。

菜单栏面板显示按持续工作估算的下次自动提醒时间；暂停、共享或休息中不显示可能误导的时间预测。距下一次提醒 2 分钟内标记即将提醒。电源选项在启动前也可配置；关闭防系统睡眠同时关闭保持点亮，开启保持点亮同时开启防系统睡眠。两项皆关时不能启动需要保持唤醒的会话；运行中关掉防睡眠会停止断言，Agent 暂停仍可单独恢复。

提醒浮层高度随单项/合并及展开状态调整，展开时保持所选屏幕角落锚点；文字不得靠压缩行高隐藏，内容超过可用屏幕时允许滚动。

显示器配置变化时，已显示的提醒和休息浮层应迁移到仍可用的目标屏幕（固定屏幕缺失时回退主屏），保留倒计时和展开状态，不应直接丢弃已经展示的弱提醒。

## 2026-09-07 勿扰联动需求变更（Accepted，采用官方 Focus Filter）

FB-007 的自动识别目标改为 macOS 勿扰，取消飞书会议专属识别方向。用户投屏时自行开启勿扰；FlowBreak 只跟随状态抑制自动提醒/声音，不负责开关系统勿扰。保留手动静默兜底，退出自动静默不得清除手动静默。用户已接受官方 Focus Filter 的一次配置，参见迭代 0007。旧版共享静默说明保留为历史，不代表自动勿扰已经实现。

用户已接受一次系统配置，采用 ADR-0005 官方 Focus Filter。勿扰仅增加展示静默来源，普通空闲/Agent/休息计时规则不变；手动与系统静默均关闭后才经过缓冲恢复。未知查询错误明确显示且保守静默；无匹配过滤条件显示未激活/未配置，不声称系统勿扰关闭。

菜单栏入口必须能可靠打开/关闭主面板；右键提供独立于主面板布局的“打开 FlowBreak / 退出”菜单。再次打开正在运行的应用时显示主面板，以便恢复访问。见迭代 0008。

所有自定义按钮的完整视觉区域都应可点击，并在悬停与按下时反馈；主要按钮最低 40 pt 高，紧凑文字/图标操作最低 32 pt 高并增加内边距。禁用时不显示可点击的悬停效果。原生开关和选择器保留系统交互。见迭代 0009。

设置侧栏图标使用固定宽度列，文字起点保持一致；选中与悬停共用完整行边界，不叠加错位背景。菜单栏弹出层的箭头和面板主体使用连续的系统材质，并共同响应应用外观设置。

Agent / 保持唤醒模式卡片的填充、边框、悬停、按下与点击区域共用同一个圆角边界，不在卡片外另加悬停底板。

应用提供绿色叶子 AppIcon；支持安装到 Applications。通用设置提供登录时启动开关，读取系统实际状态；仅用户启用时注册，不在每次启动时重新开启用户已关闭的登录项。需系统批准或失败时明确提示。

提醒浮层在普通应用、浮动和模态窗口之上显示，不抢键盘焦点；点击其他应用、切换前台或失去焦点不关闭提醒。保留已配置的自动收起时长，以及显式关闭、休息、延迟和静默规则；不承诺覆盖系统安全界面。见 ADR-0008。

## 2026-09-07 开源政策（Accepted）

FB-012：准备在 GitHub 以 MIT 公开源码；项目完全通过 Vibe Coding 开发，不接受外部贡献（包括 Pull Request），允许按 MIT 使用、Fork 和自行修改。作者已确认现有 Git 作者姓名及邮箱可公开。本次仅检查与准备，不配置远端、不推送或发布；此前“本地 Git 无远端”描述保留为历史状态。见迭代 0014。

## 2026-10-12 状态栏垂直对齐（Accepted）

FB-001、FB-011：状态栏图标和倒计时按可见内容垂直居中，中文/英文、分钟/秒均保持一致。保留等宽数字、分钟向上取整和不足一分钟显示秒的规则，以及原生左右键操作与系统深浅色着色。辅助功能应包含应用名和当前倒计时。见 [迭代 0016](../iterations/0016-menu-bar-alignment/plan.md) 与 [ADR-0009](../decisions/0009-menu-bar-label.md)。

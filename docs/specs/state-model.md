# 状态与时间语义

关联：FB-002—FB-010；[ADR-0001](../decisions/0001-native-foundation.md)。

## 分离维度

- 工作累计：eyeElapsed、movementElapsed。
- 主动休息：无 / 护眼 / 起身；输入验证后完成或中断。
- 计时暂停：Agent、锁屏/睡眠、普通无操作等原因集合。
- 提醒调度：到期、合并、静默截止时间、上次展示、重复提醒节流。
- 电源：独立断言与截止时间；人工接管不能释放断言。

`WorkSession` 负责累计；`BreakEngine` 处理合并、延迟、休息、空闲、Agent 和恢复。核心仍需系统适配，电源布尔值表示请求意图，不证明实际断言存在。完整运行语义见 ADR-0003。

## 计时与展示

锁屏/睡眠/Agent 暂停不累计；普通无操作达到暂停阈值冻结。共享覆盖普通无操作，但不覆盖明确锁屏/睡眠或 Agent 暂停。护眼休息只冻结护眼；起身休息冻结两者。提醒展示与累计独立：共享、暂停、休息、锁屏和延迟期间不自动展示。

运行中按单调时间差累计；短暂停顿不可依赖 Timer 回调次数。自然休息时长从最后一次有效输入或明确离开事件计算。锁屏、睡眠重叠只计一次。重启用版本化快照与墙钟辅助恢复；负时间差保留累计并记录异常，不宣称完成休息。

## 关键时间线

| 场景 | 预期 | 当前验证 |
|---|---|---|
| 累计 1200 秒，护眼 20 秒 | eye=0，movement=1220 | 核心测试 |
| 护眼到第 10 秒被中断，再工作 5 秒 | eye=1205，movement=1215 | 核心测试；真实输入检测未实现 |
| 起身休息完整完成 | 两者清零 | 核心测试；倒计时验证未实现 |
| 第 100 秒启动 Agent，600 秒后人工接管，再工作 10 秒 | 计时继续累计到 110；保持唤醒意图仍为 true | 核心测试；实际电源适配未实现 |
| 第 40/60 分钟 | suggested / overdue | 核心测试；自动展示未实现 |
| 护眼延迟 5 分钟，2 分钟后起身达到 60 分钟 | 等原静默截止后合并展示强提醒 | 核心测试通过，系统适配待接入 |
| 共享第 35 至 67 分钟 | 继续累计、无自动提示；结束缓冲后合并一次 | deferred 检测；调度 planned |
| 无操作 2 至 5 分钟 | 冻结后续计时，恢复不清零 | 核心测试通过，系统适配待接入 |
| 无操作至少 5 分钟 | 恢复时清除两类待处理并重新计时 | 核心测试通过，系统适配待接入 |

`BreakEngine` 内保持独立调度字段；后续 `AppModel` 串行接入系统事件。停止计时和保持唤醒由不同动作控制。
